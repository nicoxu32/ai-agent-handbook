# 讲讲 token 是什么、token 计费大概怎么算，以及为什么优化 token 消耗很重要？有哪些常见优化手段？

## 面试题

<!-- field:doubao/db-tech-06/title -->
讲讲 token 是什么、token 计费大概怎么算，以及为什么优化 token 消耗很重要？有哪些常见优化手段？
<!-- /field -->

## 回答框架

<!-- field:doubao/db-tech-06/framework -->
1. token 概念：模型处理文本的最小单位（约等于"半个词/一段字"），输入输出都计费
2. 计费逻辑：输入 token + 输出 token，通常按量计费、量大可谈价格
3. 为什么重要：直接决定成本、也影响延迟和体验；AI 产品是"卖得越多成本越高"
4. 优化手段：提示词精简、缓存复用、选更小/更快模型、RAG 按需注入、控制输出长度、批处理
<!-- /field -->

## 口述参考答案

<!-- field:doubao/db-tech-06/answer -->
"我先讲 token 是什么。**token 是模型处理文本的最小单位**——它不是按'字'也不是按'词'，而是模型自己切分出来的最小片段，中文里一个 token 大概对应不到一个字或一两个字。你发给模型的提示词、以及模型回复的内容，都会被切成一串 token 来处理。**模型每次回答，输入和输出都会消耗 token，也都按 token 计费。**

计费逻辑其实很直白：**总费用 = 输入 token 数 × 单价 + 输出 token 数 × 单价**，按量收费。通常输出 token 的单价还会比输入贵一些。对用量大的企业，可以谈包量或更优惠的价格，但单位成本这个逻辑是固定的。

那为什么优化 token 消耗很重要？我讲三点，它不只是一个省钱问题。

**第一，它直接决定成本，而且 AI 产品和传统软件不一样。** 传统软件边际成本趋近于零，而 AI 产品**每次调用都花钱，用的人越多、成本越高**。如果不控 token，很可能出现'产品火了、成本跟着爆了'、卖得越多亏得越多的情况。所以 token 优化是 AI 产品能不能持续盈利的关键。

**第二，它影响延迟和体验。** token 是逐字生成的，输出越长，用户等得越久。控 token 不只是省钱，也是让响应更快、体验更顺。

**第三，它间接影响质量。** 垃圾输入多、上下文塞得太满，模型反而容易抓不住重点、答偏。所以优化 token 往往和提升效果是一回事。

那常见的优化手段有哪些？我按从轻到重讲几个。

**第一个，提示词精简。** 把不必要的废话、重复指令删掉，用最少的字说清楚需求，这是最基础也最立竿见影的。

**第二个，缓存复用。** 用户的常见问题、固定的系统指令，很多是重复的。命中缓存就可以大幅省掉输入 token 的重复开销，对高频场景效果很明显。

**第三个，选更小、更快的模型。** 同一个任务，如果轻量模型效果已经够用，就不用每次都用最强的大模型——这是从模型层面降本。

**第四个，RAG 按需注入。** 不要一股脑把整份长文档塞进上下文，而是只把和问题相关的片段捞进来，既省 token 又提升准确度。

**第五个，控制输出长度并做结构化。** 在提示词里明确限制回复长度、要求直接给要点，避免模型啰嗦输出一堆无效 token。

所以我的理解是：**token 优化本质是在'成本、延迟、质量'三者之间找平衡**，它不是纯粹的抠成本，而是 AI 产品能不能健康运转的工程基本功。产品和技术在这里要一起使劲，把每一分 token 都花在刀刃上。"
